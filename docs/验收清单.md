# 基础功能与验收清单

## 功能范围

| 模块 | 验收行为 |
| --- | --- |
| 开始 | 初始计数为0、分类关闭；开启后秒表与记录同时生效 |
| 通用 | 点击记录生成一条人数1、类别通用的明细 |
| 分类 | 开关开启后只显示已购买/未购买计数按钮；切换不改变已有明细 |
| 暂停/继续 | 暂停禁用计数并冻结秒表；继续后接着计时 |
| 结束 | 确认后归档，当前列表清空，恢复两个开关 |
| 时间 | 同一秒内多次点击保留多条记录；计时不因修改手机时间跳变 |
| 地址 | 成功显示实际地址；失败不伪造地址；经纬度不在前端显示 |
| 历史 | 时间范围匹配已结束场次；点开显示完整明细及有效计时 |
| 分析 | 按所选范围的已结束记录统计；无记录不除零；通用不计转化率 |
| 导出 | 真正xlsx，含明细/汇总两个工作表及经纬度 |
| 分享 | 微信安装时通过系统面板选择微信；无微信时可保存文件 |
| 主题 | 手动浅色/深色和跟随系统可用，重启保留设置 |
| 恢复 | 同次开机进程重建恢复场次；设备重启后保守转为暂停 |

## 发布前真机验收

以下需要在目标安卓手机上实测，不能用静态编译代替：

- 手机定位权限拒绝、仅大致位置、GPS开关关闭/开启、网络断开、室内定位与地址解析。
- 微信实际接收xlsx，联系人选择、发送及微信内打开；WPS/Excel读取。
- 不同字体缩放、小屏幕、横屏、系统明暗自动切换。
- 快速连续点击、系统回收、关机重启、保存文档时进程重建。
- 长时间运行耗电与大规模历史记录性能。

本工程提供首版试用APK。构建、静态检查、文件格式验证和真实设备行为的验证结论分别记录在交付说明中，未执行的检查不视作已通过。
